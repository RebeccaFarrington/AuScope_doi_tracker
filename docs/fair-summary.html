AuScope FAIR Data Assessment

This page summarises automated F-UJI scores for AuScope datasets identified by their Digital Object Identifiers (DOIs), providing a quantified and operationalised indication of their alignment with the Findable, Accessible, Interoperable and Reusable (FAIR) principles.

Score colours use rounded percentages: green ≥60%, amber 40–59%, red <40%. These are dashboard thresholds, not F-UJI benchmarks. Assessment coverage uses a separate scale: green ≥80%, amber 50–79%, red <50%.

By Platform — Excluding new DOIs

Highlight — Findability, persistent identifiers: All 47 datasets with improved overall scores were from EarthBank, each gaining credit for persistent identifier recognition. Some also gained credit on other checks.

Lowlight — Reusability, description of data content: Of the 79 datasets with lower overall scores, 66 AusPASS and 12 EarthBank datasets received fewer points for metadata describing the data’s content, despite still passing that check. The remaining AusPASS dataset lost credit for structured metadata under Interoperability. Different F-UJI software versions were used, so these changes require investigation before being interpreted as reduced data quality or reusability.

Changes are calculated before rounding. Score changes may reflect metadata or assessment behaviour.

F-UJI maturity levels

This chart shows all 17 F-UJI assessment metrics together, grouped by FAIR principle. Each bar shows the distribution of maturity levels across the selected datasets. Maturity comes directly from F-UJI’s test outcomes; it is not calculated from our percentage-score colour thresholds.

F-UJI defines four levels: 0 Incomplete, 1 Initial, 2 Moderate and 3 Advanced. A metric’s maturity is the highest level associated with a passed test. References: F-UJI maturity labels and maturity calculation. The blue and purple palette below distinguishes these levels from the dashboard’s score indicators.

0 Incomplete 1 Initial 2 Moderate 3 Advanced Unavailable

Unavailable means no valid metric maturity result was stored; it is not classified as Incomplete. Results describe evidence detected by the automated assessment. Principle descriptions are paraphrased from Wilkinson et al. (2016); test descriptions follow the FAIRsFAIR assessment metrics v0.8. These are metric-level results; underlying subtest details are not retained in this dashboard.
